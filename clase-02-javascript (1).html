02

Recordar una decisión sencilla

Un if comprueba una condición. Si se cumple, ejecuta su bloque; si no se cumple, ejecuta el bloque de else.

Resultado en la consola
Puedes comprar el libro
  1. La condición es saldo >= 10.
  2. Como 12 es mayor o igual que 10, la condición es true.
  3. Se muestra el primer mensaje. El bloque de else no se ejecuta.
Prueba el cambio: sustituye 12 por 8. Guarda y recarga. Debe aparecer Te falta dinero. Después prueba con 10: debe permitir la compra.

Recuerda: > significa «mayor que» y >=, «mayor o igual que». El valor del límite también cuenta cuando usamos >=.

03

Añadir otra opción con else if

A veces necesitamos elegir entre tres resultados. Para añadir una segunda condición, escribimos else if entre if y else.

Vamos a clasificar una temperatura: desde 30 grados, hace calor; desde 20 hasta menos de 30, la temperatura es agradable; por debajo de 20, hace fresco.

Resultado en la consola
La temperatura es agradable
  1. Se comprueba temperatura >= 30. Con 24 es falso.
  2. Se comprueba temperatura >= 20. Con 24 es verdadero.
  3. Se muestra el segundo mensaje y se termina la cadena de condiciones.
El orden importa. Se ejecuta el primer bloque cuya condición se cumpla. Aquí comprobamos primero >= 30. Si comprobáramos antes >= 20, una temperatura de 35 también entraría en ese primer bloque.

No hace falta repetir temperatura < 30 en la segunda condición: solo llegamos a ella cuando la primera ha sido falsa. else recoge el resto de los casos y no lleva condición.

Comprobar los límites

Cambia únicamente el valor de temperatura y repite el proceso de guardar y recargar.

TemperaturaMensaje esperado
19Hace fresco
20La temperatura es agradable
29La temperatura es agradable
30Hace calor

06

Cumplir una condición u otra: ||

|| se lee «o». Al combinar dos comparaciones, basta con que una sea verdadera. Si las dos son verdaderas, el resultado también es verdadero.

Una cafetería ofrece una promoción los lunes o los miércoles.

Resultado en la consola
Hoy hay promoción

La comparación se escribe completa a ambos lados del operador: dia === "lunes" y dia === "miércoles". || son dos barras verticales seguidas.

Ahora prueba: cambia el día por "miércoles" y después por "martes". El miércoles debe haber promoción; el martes, no. Copia las palabras exactamente, incluida la tilde.

Elegir el operador

La regla dice…OperadorQué se necesita
Un requisito y otro&&Los dos.
Un requisito o el otro||Al menos uno.

Errores que conviene revisar

  • Escribe else if en dos palabras; elseif no es correcto.
  • No pongas ; entre la condición del if y su llave de apertura.
  • Escribe && y || con dos símbolos, no con uno.
  • Repite la comparación completa: dia === "lunes" || dia === "miércoles".
  • Usa números sin comillas para las edades, notas, temperaturas y precios.
  • Si aparece ReferenceError, comprueba los nombres de las variables. Si aparece SyntaxError, revisa comillas, paréntesis y llaves.
Cómo comprobar una solución
  1. Lee la regla e identifica los datos y las condiciones.
  2. Prueba un caso que cumpla la condición y otro que no.
  3. Prueba también el valor exacto del límite: por ejemplo, 18 si la regla utiliza >= 18.
  4. Comprueba que los mensajes sean claros y que no haya errores en la consola.

01

if / else

¿Hace falta chaqueta?

Declara una constante temperatura con valor 15.

  • Si la temperatura es menor que 18, muestra Lleva una chaqueta.
  • En caso contrario, muestra No hace falta chaqueta.

Pruebas: con 15 y 17 debe recomendar chaqueta. Con 18 y 23 no debe recomendarla.

02

else if

Clasificar una nota

Declara una constante nota con un número entre 0 y 10. Utiliza if, else if y else para mostrar:

  • Excelente si la nota es 9 o más.
  • Aprobado si la nota es 5 o más, pero menor que 9.
  • Necesita mejorar si la nota es menor que 5.

Comprueba primero la condición de la nota más alta. Para este ejercicio, utiliza siempre notas válidas entre 0 y 10.

Pruebas: 4 → Necesita mejorar; 5 y 8 → Aprobado; 9 y 10 → Excelente.

03

Operador &&

Subir a una atracción

Declara las constantes edad y altura. La altura se expresa en centímetros.

Para subir se necesitan 12 años o más y una altura de 140 cm o más. Si se cumplen ambos requisitos, muestra Puedes subir. En caso contrario, muestra No cumples los requisitos.

Pruebas: edad 12 y altura 140 → puede subir; edad 11 y altura 150 → no puede; edad 14 y altura 139 → no puede. Usa && para unir las dos comparaciones.

04

Operador ||

Envío gratuito

Declara una constante importeCompra y otra llamada esSocio, con valor true o false.

El envío es gratuito si la compra alcanza los 30 € o la persona es socia. Muestra Envío gratuito cuando se cumpla al menos una de las condiciones y Envío de pago en caso contrario.

Pruebas: compra de 30 € y false → gratuito; compra de 12 € y true → gratuito; compra de 12 € y false → de pago; compra de 30 € y true → gratuito.

05

Variables y varias opciones

Precio de una entrada

Declara una constante edad y una variable precioEntrada con let. Utiliza un valor inicial de 0 para el precio.

Asigna el precio que corresponda mediante una cadena de if / else if / else:

  • Menores de 6 años: entrada gratuita, precio 0 €.
  • Desde 6 hasta 15 años: precio 5 €.
  • A partir de 16 años: precio 8 €.

Al terminar las condiciones, muestra la edad y el precio con etiquetas claras. Para este ejercicio, utiliza edades de 0 años en adelante.

Pruebas: edad 5 → precio 0 €; edades 6 y 15 → precio 5 €; edades 16 y 30 → precio 8 €. Comprueba especialmente las edades 6 y 16.
