💻 Curso de Programación Web: Introducción a HTML

Aprende las bases de la estructura de internet paso a paso

1. ¿Qué es HTML?

HTML significa HyperText Markup Language (Lenguaje de Marcado de Hipertexto).

💡 Idea Clave: HTML no es un lenguaje de programación con lógica compleja (como Python o JavaScript). Es un lenguaje de marcado que define la estructura y el contenido de una página web.

Analogía del Cuerpo Humano en la Web:

  • HTML: Es el esqueleto (define los huesos: títulos, textos, botones, imágenes).
  • CSS: Es la piel y ropa (aporta diseño, colores y estilos).
  • JavaScript: Es el sistema nervioso (añade interactividad y movimiento).

Sintaxis de una etiqueta

HTML funciona mediante etiquetas que encierran el contenido:

<nombre_etiqueta> Contenido aquí </nombre_etiqueta>

¿Qué hace el navegador con HTML?

Cuando abres una página, el navegador lee el archivo HTML de arriba hacia abajo, interpreta cada etiqueta y construye una representación interna llamada DOM. Gracias a esa estructura, CSS puede aplicar estilos y JavaScript puede modificar el contenido.

Importante: un archivo HTML se puede abrir directamente en el navegador, pero cuando una web crece suele servirse desde un servidor para cargar imágenes, hojas de estilo, scripts y datos externos.

2. Estructura Fundamental de un Documento

Todo archivo HTML debe tener una estructura mínima obligatoria para que el navegador lo interprete correctamente:

<!DOCTYPE html>

Le indica al navegador que estamos usando la versión moderna: HTML5.

<html>

La etiqueta raíz que envuelve absolutamente todo el código web.

<head>

Contiene metadatos, título de la pestaña e información "invisible" para el usuario.

<body>

El cuerpo del documento: todo lo que escribas aquí será visible en pantalla.

Metadatos habituales

Dentro de <head> se colocan datos que ayudan al navegador, a los buscadores y a los dispositivos móviles:

  • <meta charset="UTF-8">: permite usar acentos, eñes y caracteres especiales correctamente.
  • <meta name="viewport" content="width=device-width, initial-scale=1.0">: adapta la página a móviles y tablets.
  • <title>: define el texto que aparece en la pestaña del navegador.
  • <link rel="stylesheet" href="estilos.css">: conecta un archivo CSS externo.

3. Las Etiquetas Más Utilizadas

Para construir la mayoría de los sitios web, solo necesitas dominar estas etiquetas fundamentales:

  • Títulos (Encabezados): <h1> al <h6>
    <h1> es el título principal y más grande; <h6> el más pequeño.
  • Párrafos de texto: <p>
    Se usa para bloques de texto normal.
  • Enlace a otra página: <a href="https://...">Texto del enlace</a>
  • Listas: <ul> (desordenada) y <ol> (ordenada), usando <li> para cada ítem.
  • Botón interactivo: <button>Hacer clic</button>
  • Imagen: <img src="foto.jpg" alt="Descripción de la imagen">
    La etiqueta <img> no necesita cierre y el atributo alt mejora la accesibilidad.
  • Contenedores: <div> y <span>
    Sirven para agrupar contenido, aunque conviene preferir etiquetas semánticas cuando tengan sentido.

Atributos: información extra para una etiqueta

Los atributos se escriben dentro de la etiqueta de apertura y modifican su comportamiento. Por ejemplo, href indica el destino de un enlace, src indica la ruta de una imagen e id permite identificar un elemento concreto.

Cómo añadir una imagen

Si la imagen está en la misma carpeta que el archivo HTML, puedes escribir solo el nombre del archivo dentro del atributo src. En este caso, la imagen se llama gt3.webp.

<img src="gt3.webp" alt="Porsche 911 GT3 en color blanco">

Recuerda: src indica dónde está la imagen y alt describe la imagen para lectores de pantalla o para cuando no pueda cargarse.

5. Paso a Paso: Tu Turno de Programar

Guía a tus alumnos para que ejecuten su primer archivo HTML en sus propias computadoras:

  1. Abre el editor de texto: Busca el Bloc de notas (Windows) o TextEdit (Mac).
  2. Copia el código de ejemplo: Ve a la pestaña "4. Demo Interactiva" y pulsa en "Copiar este código".
  3. Pega el contenido: Pégalo en la ventana en blanco de tu editor de texto.
  4. Guarda el archivo correctamente:
    • Haz clic en Archivo > Guardar como...
    • Nombra el archivo como mi_pagina.html (es fundamental escribir la extensión .html).
    • En tipo de documento, selecciona "Todos los archivos" si usas Bloc de notas.
  5. Abre tu sitio web: Ve a la carpeta donde lo guardaste y haz doble clic en el archivo. ¡Se abrirá en tu navegador!

6. HTML Semántico y Buenas Prácticas

El HTML semántico consiste en usar etiquetas que describen el significado del contenido. Esto ayuda a los navegadores, a los buscadores y a las herramientas de accesibilidad.

<header>

Representa la cabecera de una página o sección. Suele contener el título, el logo o una introducción.

<nav>

Agrupa enlaces de navegación, como menús principales o accesos a secciones importantes.

<main>

Contiene el contenido principal de la página. Normalmente debe aparecer una sola vez por documento.

<section>

Divide la página en bloques temáticos, por ejemplo una presentación, una galería o una zona de contacto.

<article>

Se usa para contenido independiente, como una noticia, una ficha, una reseña o una entrada de blog.

<footer>

Marca el pie de página o de una sección. Puede incluir autoría, enlaces legales o información de contacto.

Buenas prácticas esenciales

  • Usa un solo <h1> principal y organiza los títulos en orden lógico.
  • Escribe textos alternativos claros en las imágenes con alt.
  • No uses etiquetas solo por cómo se ven; usa CSS para el diseño y HTML para la estructura.
  • Indenta el código para que sea fácil de leer y revisar.
  • Valida que todas las etiquetas abiertas estén correctamente cerradas.

7. Mini Proyecto: Página Personal

Para practicar, crea una página personal sencilla. El objetivo es combinar estructura, contenido y algo de organización visual.

Requisitos del proyecto

  1. Un título principal con tu nombre.
  2. Un párrafo de presentación de 3 o 4 líneas.
  3. Una lista con tus habilidades, intereses o asignaturas favoritas.
  4. Una imagen con atributo alt.
  5. Un enlace a una web que consultes para aprender.
  6. Un botón que muestre un mensaje usando alert().
Consejo: empieza por el contenido en HTML. Cuando la estructura esté clara, añade CSS para colores, tamaños, márgenes y distribución.
