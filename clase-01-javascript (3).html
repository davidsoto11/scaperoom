01

Qué vamos a hacer

JavaScript es un lenguaje de programación. Permite escribir instrucciones para realizar cálculos, trabajar con datos y añadir comportamiento a una página web: responder a un clic, comprobar un formulario o actualizar un resultado.

HTML

Define el contenido y su estructura: títulos, párrafos, botones…

CSS

Define la presentación: colores, tamaños y distribución.

JavaScript

Define el comportamiento y las operaciones que realiza el programa.

En esta clase escribirás el código en Visual Studio Code y lo ejecutarás en el navegador. La consola del navegador será el lugar donde verás los resultados.

Al terminar podrás
  • Crear y conectar un archivo HTML y un archivo JavaScript.
  • Mostrar mensajes y leer errores en la consola.
  • Guardar datos con const y let.
  • Combinar textos, hacer cálculos y tomar decisiones con if / else.

Antes de empezar

Necesitas Visual Studio Code instalado y un navegador de escritorio, como Chrome, Edge o Firefox. Si falta el editor, descárgalo desde code.visualstudio.com, completa la instalación y ábrelo.

Para esta práctica basta con el editor y el navegador. No hace falta instalar Node.js, usar la terminal ni añadir extensiones. Visual Studio Code incluye soporte para JavaScript.

03

Ver y actualizar los resultados

  1. En el navegador, haz clic derecho sobre la página y selecciona Inspeccionar (Inspect).
  2. Dentro de las herramientas que se abren, selecciona la pestaña Consola (Console).
  3. Recarga la página con el botón de recarga del navegador. Debe aparecer Hola, JavaScript.
  4. Vuelve a Visual Studio Code, cambia el mensaje por Hola, estoy aprendiendo JavaScript y guarda app.js.

04

Reglas básicas de escritura

  • Mayúsculas y minúsculas importan. nombre y Nombre son identificadores distintos. Escribe console.log, respetando las minúsculas.
  • Usa comillas para el texto. Puedes usar "Hola" o 'Hola', pero debes cerrar con el mismo tipo de comilla. Usa las comillas rectas del teclado.
  • Escribe una instrucción por línea. En estos apuntes terminaremos las instrucciones simples con ; para mantener un estilo uniforme.
  • Revisa los signos por parejas. Los paréntesis (), las llaves {} y las comillas deben abrirse y cerrarse.
  • Utiliza la sangría. El código dentro de un bloque se escribe un poco más a la derecha para que se lea mejor.

Comentarios

Un comentario es una anotación del código que no se ejecuta. // comenta hasta el final de la línea; /* ... */ permite comentar varias líneas.

Guardar información: const y let

Una variable permite guardar un valor y utilizarlo mediante un nombre. Para crearla, escribimos una declaración.

Resultado en la consola
Lucía
10
15
ParteQué significa
const / letDeclara una variable.
nombre / puntosEs el nombre con el que accedemos al valor.
=Asigna el valor que aparece a la derecha.
"Lucía" / 10Es el valor inicial.

¿Cuándo se usa cada una?

  • Usa const cuando no vayas a reasignar la variable. Debes darle un valor al declararla.
  • Usa let cuando necesites asignarle otro valor durante el programa.

En puntos = 15; cambiamos el valor sin escribir otra vez let. El signo = asigna; no comprueba si dos valores son iguales.

Regla práctica: empieza con const y elige let cuando el valor necesite cambiar. Si intentas hacer nombre = "Mario"; después de declarar nombre con const, se producirá un error.

Nombres que se entiendan

Utiliza nombres como precioEntrada, cantidad o totalCompra. No pueden llevar espacios ni empezar por un número. En estos apuntes usaremos camelCase: primera palabra en minúscula y las siguientes con inicial mayúscula.

let totalCompra = 0; es válido. let total compra = 0; y let 2total = 0; no lo son. Tampoco puedes usar palabras reservadas, como const, como nombre de variable.

Number() convierte estos textos numéricos en números. Sin la conversión, + concatena. Un texto que no representa un número, como Number("hola"), produce NaN, que indica un resultado numérico no válido.

Antes de calcular: comprueba si el dato lleva comillas. Usa números sin comillas para las cantidades que escribas directamente en el código.

Una comparación devuelve true o false. Podemos usar ese resultado para elegir qué instrucciones se ejecutan.

OperadorSignificadoEjemplo

En esta clase usaremos === para comparar igualdad. Recuerda: = sirve para asignar.

11

Qué hacer cuando algo falla

Lee primero el mensaje de la consola. Si señala app.js:4, se refiere a la línea 4 de ese archivo. El fallo puede estar en esa línea o justo antes, por ejemplo una comilla sin cerrar.

SíntomaQué revisar
No aparece ningún mensaje.Guarda app.js, recarga el navegador y verifica el nombre en src="app.js". Asegúrate de que la consola no tenga filtros activos que oculten los mensajes.
SyntaxErrorBusca comillas, paréntesis o llaves sin cerrar, o símbolos mal escritos.
ReferenceErrorComprueba que la variable esté declarada antes de usarla y que su nombre coincida exactamente.
Assignment to constant variableHas intentado reasignar una variable declarada con const. Si su valor debe cambiar, declárala con let.
Identifier ... has already been declaredPuede que hayas pegado varios ejemplos con el mismo nombre de variable. Conserva solo el ejemplo que estás probando.
Aparece 105 en lugar de 15.Estás uniendo textos. Comprueba los tipos y utiliza Number() si los valores son textos numéricos.
La página muestra el título, pero el archivo JS no se carga.Comprueba que ambos archivos estén en la misma carpeta. Revisa si la consola muestra un error de archivo no encontrado.

Una entrada con descuento

Una entrada cuesta 10 €. Las personas menores de 18 años pagan 6 €. A partir de los 18 años, el precio es de 10 €.

  1. Declara una constante edad con el valor 16.
  2. Declara una variable precioEntrada con el valor 10.
  3. Utiliza un if para aplicar el precio de 6 cuando corresponda.
  4. Muestra la edad y el precio final con etiquetas claras.
  5. Repite la prueba con las edades 17, 18 y 25.

Comprobación: para 16 y 17 años, el precio es 6; para 18 y 25 años, es 10. El límite de 18 años debe resolverse correctamente.
