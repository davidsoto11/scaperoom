1. ¿Qué es CSS y por qué lo necesitas?

CSS (Cascading Style Sheets) es el lenguaje que define el diseño visual de una web: colores, tamaños, fuentes, posiciones y animaciones.

💡 Diferencia rápida: HTML coloca el texto y las imágenes (el esqueleto). CSS decide cómo se ven y dónde se ubican (la ropa, la pintura y el estilo).

2. Las 4 Propiedades de CSS más importantes

Con solo estas cuatro propiedades puedes cambiar por completo el aspecto de cualquier sitio:

background-color: #1e293b;

Cambia el color de fondo. Puedes usar colores en inglés (black, red) o códigos Hexadecimales (#ff0055).

color: #ffffff;

Cambia el color del texto.

border-radius: 20px;

Redondea las esquinas de los botones, imágenes o recuadros. Cuanto mayor sea el número, más redondo será.

padding: 15px;

Añade espacio interno alrededor del texto para que los elementos no queden apretados.

3. Fundamentos de CSS: cómo leer una regla

Una regla CSS tiene tres partes: el selector indica a qué elemento afecta, la propiedad indica qué queremos cambiar y el valor indica cómo.

selector {
    propiedad: valor;
}

p {
    color: tomato;
    font-size: 18px;
}

1. Selectores

Podemos seleccionar por etiqueta, clase o identificador.

p { color: white; }        /* etiqueta */
.destacado { color: gold; } /* clase */
#titulo { font-size: 2rem; } /* id */

Consejo: usa clases para repetir estilos y reserva los identificadores para elementos únicos.

2. Agrupar y reutilizar

Varias clases pueden aplicarse al mismo elemento para combinar estilos.

.tarjeta { padding: 1rem; }
.importante { border: 2px solid gold; }

<div class="tarjeta importante">...

3. Unidades

px es una medida fija; % depende del elemento padre; rem depende del tamaño base de letra; vw y vh dependen de la ventana.

width: 80%;
padding: 1rem;
font-size: 18px;

4. Comentarios y orden

Los comentarios ayudan a explicar el código y el navegador no los muestra.

/* Colores principales */
body { background: #111827; }

Si dos reglas tienen la misma fuerza, normalmente gana la que aparece más abajo.

🧠 Pregunta para la clase: ¿qué selector usarías para cambiar todos los párrafos y cuál para cambiar solo el párrafo con la clase .aviso?

4. Modelo de caja y colocación de elementos

En CSS, casi todo se comporta como una caja. Entender sus partes evita que los elementos queden demasiado juntos o se descoloquen.

Contenido
padding → borde → margen

El modelo de caja

  • content: el texto o imagen.
  • padding: espacio interior.
  • border: línea que rodea la caja.
  • margin: espacio exterior entre cajas.
.tarjeta {
    margin: 20px;
    padding: 16px;
    border: 2px solid white;
}

Flexbox en 4 propiedades

Flexbox permite colocar elementos en fila o columna y repartir el espacio disponible.

.menu {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 1rem;
}

📱 Diseño responsive: una web debe funcionar en móvil y ordenador. Usa porcentajes, max-width, flex-wrap y media queries cuando sea necesario. 
@media (max-width: 600px) {
    h1 { font-size: 1.5rem; }
    .menu { flex-direction: column; }
}

5. La cascada y buenas prácticas

La “C” de CSS significa cascading: cuando varias reglas afectan a un elemento, el navegador decide cuál tiene prioridad.

Prioridad orientativa

  1. Estilos en línea: style="..."
  2. Identificadores: #menu
  3. Clases y pseudo-clases: .boton:hover
  4. Etiquetas: button

Errores frecuentes

  • Olvidar el punto delante de una clase.
  • Olvidar el punto y coma final.
  • Escribir mal una propiedad.
  • No cerrar una llave }.
  • Usar demasiados estilos en línea.
🔎 Herramienta profesional: con “Inspeccionar” del navegador puedes seleccionar un elemento, ver sus estilos y probar cambios sin modificar todavía el archivo.

6. Crear un proyecto HTML + CSS desde cero

En esta práctica vamos a crear una tarjeta de presentación sencilla. El objetivo es aprender el flujo de trabajo completo: crear una carpeta, crear dos archivos, conectarlos y comprobar el resultado.

🎯 Resultado final: una página con un título, una descripción, un botón y estilos guardados en un archivo CSS independiente.
1

Crear la carpeta del proyecto

Crea una carpeta llamada mi-primera-web en el Escritorio o dentro de tu carpeta de clase.

📁 mi-primera-web/

Es importante que los dos archivos siguientes estén dentro de esta misma carpeta.

2

Crear el archivo HTML

Abre Visual Studio Code, Bloc de notas o el editor que utilicéis. Crea un archivo llamado exactamente index.html.

Escribe esta estructura básica:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mi primera web</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <main class="tarjeta">
        <h1>Hola, soy Ana</h1>
        <p>Estoy aprendiendo HTML y CSS.</p>
        <a class="boton" href="#">Ver mi perfil</a>
    </main>
</body>
</html>

Guarda el archivo dentro de mi-primera-web.

3

Crear el archivo CSS

En la misma carpeta, crea un segundo archivo llamado exactamente styles.css.

Añade estos estilos:

* {
    box-sizing: border-box;
}

body {
    margin: 0;
    min-height: 100vh;
    display: grid;
    place-items: center;
    background-color: #e0f2fe;
    font-family: Arial, sans-serif;
}

.tarjeta {
    width: min(90%, 420px);
    padding: 2rem;
    text-align: center;
    background-color: white;
    border-radius: 16px;
    box-shadow: 0 8px 20px rgba(0, 0, 0, 0.15);
}

h1 {
    color: #7c3aed;
}

.boton {
    display: inline-block;
    padding: 0.8rem 1.2rem;
    color: white;
    background-color: #7c3aed;
    border-radius: 8px;
    text-decoration: none;
}

.boton:hover {
    background-color: #ec4899;
}
4

Comprobar la conexión

La conexión entre HTML y CSS se hace con esta línea dentro de <head>:

<link rel="stylesheet" href="styles.css">

Significa: “carga el archivo CSS que está en esta misma carpeta”. El nombre debe coincidir exactamente, incluyendo mayúsculas y minúsculas.

⚠️ Si el archivo se llama style.css pero en HTML escribes styles.css, los estilos no aparecerán.
5

Abrir la página en el navegador

  1. Guarda los dos archivos.
  2. Abre la carpeta mi-primera-web.
  3. Haz doble clic en index.html.
  4. Comprueba que aparece la tarjeta morada.

Si usáis Visual Studio Code, también podéis instalar Live Server, hacer clic derecho sobre index.html y elegir Open with Live Server.

  • ¿La carpeta contiene index.html y styles.css?
  • ¿El enlace está dentro de <head>?

7. El Secreto de la Interactividad: :hover

La pseudo-clase :hover permite cambiar el estilo de un botón o enlace cuando el usuario pasa el cursor por encima.

Ejemplo de código:

button {
    background-color: #8b5cf6;
    transition: 0.3s; /* Para que el cambio sea suave */
}

button:hover {
    background-color: #ec4899; /* Cambia a rosa al pasar el ratón */
    transform: scale(1.08);    /* Crece un 8% */
}
